# Hex Capture feature
Теперь юниты, на которых добавлен компонент CapturePowerComponent могут захватывать гексы. Система HexCaptureStatusCalculationSystem считает влияние каждого игрока в гексе, и меняет значение владения в зависимости от соотношения сил. Незанятые гексы вновь становятся нейтральными.

# Отображение (редактор)
 Используйте HexCaptureStatusDebugDrawer для визуального отображения владения гексами
 
# Параметры
 Текущая сила захвата юнитов фиксирована. Скорость действий захвата фиксирована в CaptureConstants.
