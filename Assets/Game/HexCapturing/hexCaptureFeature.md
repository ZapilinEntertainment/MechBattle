# Hex Capture feature
Сущности, на которых добавлен CaptureBehaviourComponent участвуют в определении принадлежности гекса тому или иному игроку. Система HexCaptureStatusCalculationSystem считает влияние каждого игрока в гексе, и меняет значение владение в зависимости от соотношения сил. Незанятые гексы вновь становятся нейтральными. Коэффициенты скорости задаются в CaptureConstants.

# Типы взаимодействия
 Существует 3 варианта влияния на захват клетки (CaptureBehaviourType):
 1) CanCapture - активно захватывает (юнит)
 2) ResistCapturing - сопротивляется захвату (удерживает значение), но не захватывает само (здание)
 3) Capturable - меняет владельца в зависимости от того, кому принадлежит гекс (небоевые юниты и здания)
 
# Расчёт
 - Считаем силу захвата и силу сопротивления каждого игрока в гексе
 - Выбираем игрока с самой высокой силой захвата
 - Если других игроков нет, просто захватываем пропорционально силе захвата
 - Если в гексе есть другой игрок (учитываем только 1 соперника), то сильнейший может захватить только до (1 - resist/total) x 100 %, где resist - сила сопротивления более слабого, а total - суммы их активных и resist сил. Resist обеспечивают оборонительные здания, так что для полного контроля их нужно разрушить. Продвижение захвата при конфликте медленее, чем при случае, когда в гексе 1 игрок (задается константой CaptureConstants)

# Отображение (редактор)
 Используйте HexCaptureStatusDebugDrawer для визуального отображения владения гексами
 
# Параметры
 Текущая сила захвата юнитов определяется конфигом юнита.
