# Прожектайлы
Отдельная сабфича внутри weapons, описывающая поведение снарядов.

## Создание
Прожектайлы не создаются напрямую в точке запроса, вместо этого создается запрос через ProjectileRequestsFactory, который затем будет обработан ProjectileCreateSystem. Таким образом все прожектайлы спаунятся в один момент фрейма.

## Конфиги
Все данные по прожектайлам хранятся в scriptable object ProjectilesData. Так как внутри игровой логики вместо строк используются int-ключи, то дополнительно есть кэшированная версия конфига CachedProjectileDataList.
У прожектайла есть следующие настройки:
 - скорость
 - view id - ключ модели
 - ExplosionEffectKey - ключ vfx взрыва
 - Lifetime - сколько проживет прожектайл после выпуска
 - UseGravity - влияет ли гравитация на прожектайл
 
## Гравитация
Прожектайлам можно включить гравитацию, поставив галочку в конфиге
ProjectileGravityAffectionSystem будет менять скорость и вращение снаряда, симулируя гравитацию. Обратите внимание, что для таких снарядов нужно выбирать соотвествующий режим наведения и проверки линии стрельбы в конфиге оружия.

## Движение
ProjectilesMoveVectorCalculationSystem рассчитывает вектор движения снаряда.
ProjectileMoveApplySystem попытается сдвинуть снаряд на этот вектор, и если есть столновение или lifetime вышел, то взорвет его (повесит ExplodeTag)

## Взрыв
ProjectilesExplodeSystem наносит урон от прожектайла и вызывает vfx эффект.
