# Units feature
Модуль содержит системы и объекты данных, которые реализуют юнитов и их спаун.

# Создание юнита
- визуальная модель юнита должна быть addressable
- создайте scriptable object UnitConfig в папке Resources/Scriptables/UnitConfigs (или воспользуйтесь тулбаром: Scriptables/ Open unit configs) и заполните его
- через UnitSpawnRequestsFactory создайте запрос и игра спаунит юнита в указанной точке (сначала будет создана сущность, а затем добавится визуальное отображение(если создается очень много юнитов, это может произойти не сразу))

# Конфигурация юнита
Настройки UnitsConfig
 - Health - количество очков здоровья
 - CollisionAvoidancePriority - выберите тип юнита, чтобы он корректно участвовал в избегании
 - ViewId - укажите адрес addressable-префаба модели
 - TargetSearchRadius - радиус поиска ближайшего врага (для ClosestAttackTarget)
 - BehaviourKey - ключ поведения для стейта (EntityStates)
 - MoveSpeed - скорость передвижения
 - FeatureConfigs - добавьте нужные настройки в зависимости от реализуемых фич (см.ниже)
 
# Feature Appliers
 Добавляемые к проекту фичи могут реализовывать IUnitFeatureApplier, чтобы добавлять необходимые компоненты на юнита при сборке. Также в FeatureConfigs можно добавлять конфигурации, реализующие IUnitFeatureConfig, чтобы хранить набор настроек под каждую фичу. Чтобы сразу реализовать базовое считываение настроек и кэширование, наследуте апплаер от UnitFeatureApplierBase.
