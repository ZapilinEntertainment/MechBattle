# Взводы \ Squads

## Применение
Взводы управляют большими группами юнитов и контролируют их поведение

## Когда использовать
- Группы юнитов которые должны держаться вместе и атаковать одну цель

## Когда НЕ использовать
- Уникальные юниты
- неподвижные юниты
- юниты со сложной логикой атаки или передвижения

## Внутреннее устройство
- Взвод это обычная entity, с позицией и state
- Есть 4 state - Idle, Attack, Move, Guard
- Из Idle переходит в Guard если в радиусе GuardRadius замечен вражеский юнит (ищет по компоненту PrimaryTargetingObjectTag)
- является композитной целью (CompositeTargetComponent) с режимом Squad

## Регистрация зависимостей идет через SquadSubfeatureInstaller (вызывается в UnitsInstaller)

## Реализация
- Создаем взводы через SquadFactory
- Получаем юнитов через SquadHandler.GetNextMember() - работает через SquadMembersInterator, который перечисляет юнитов по фильтру
- Позицию рассчитывает система SquadPositionCalculationSystem
- SquadLossesUpdateSystem ставит взводам погибших юнитов тег SquadUpdatedTag, чтобы они пересчитали количество и обновили позиции
- Для передачи команд "снаружи" используем SquadDecreeApplier
