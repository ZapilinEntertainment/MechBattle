# Entities Map Feature
 Навигационная карта теперь представляется как набор сущностей - каждая ячейка это сущность с компонентом CellEntityComponent, и также каждый гекс это отдельная сущность с HexComponent.

# Использование
 - перебор ячеек и гексов по фильтрам
 - добавление любого количества компонентов без нужды делать отдельные списки или расширять структуру
 - каждая фича отдельно может навешивать заданные компоненты при сборке сущности (см.ниже)

# Feature-related данные для ячеек и гексов
 Если фиче требуется, чтобы на всех ячейках / гексах карты был какой-то компонент, то нужно в SceneInstall забиндить объект, реализующий INavigationCellCreationApplier / INavigationHexCreationApplier, который будет заниматься добавлением этого компонента. Фабрики автоматически получат и запишут его в свой список апплаеров и будут применять его при каждой сборке.
