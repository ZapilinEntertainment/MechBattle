# AttackTargetDefinition
Подфича базового ECS модуля, содержащая системы для назначения целей вооружению. Компонент выбранной цели - AttackTargetComponent.

# Композитные цели

## AttackTargetSpecificationSystem
Если на указанной цели стоит тег CompositeTargetComponent эта система выберет конкретный объект и поставит тег CompositeTargetSpecifiedTag.
Типы композитных целей:
- Partitions: Мех. Система выбирает ближайшую из частей (TODO: нужно сделать выбор случайным)
- Squad: получает ближайшего юнита из взвода

## CompositeTargetClearTagSystem 
Стирает тег об определении комопзитной цели на сущностях без цели атаки

# AttackTargetValidationSystem
Удаляет AttackTargetComponent если внутри - более несуществующая сущность

# Поиск ближайших целей

## ClosestAttackTargetDefineSystem
Находит ближайшую цель для сущности оружия. Запускает отдельно TargetDefineProcess, который выполняет 3 работы:
1) Выполняет PrepareTargetSearchJob - собирает данные по потенциально атакующим и выбираемыми целью сущностям, а также по ячейкам. Хэндлер этой задачи идет в World.JobHandle, так как читает из NativeStashes
2) Выполняет параллельно ClosestTargetDefineJob и LongRangeTargetDefineJob, передавая в них данных из prepare target job.
 - ClosestTargetDefineJob ищет цели для сущностей с коротким радиусом поиска (до 1 гекса) с помощью энумератора виртуального гекса - ищет цели по ячейкам сетки.
 - LongRangeTargetDefineJob ищет цели для сущностей с большим радиусом - для каждой атакующей сущности подбирает список подходящих гексов, а затем проходится по полному списку юнитов, отбрасывая их по игроку и координате гекса. 
3) обе работы пишут данные в один массив (так как и на вход им дает одинаковый массив, каждый элемент которого каждая из работ проверяет - являет ли ли он long-range или нет). 
4) как только обе работы закончены, система устанавливает их цели и ставит кулдаун-компонент

Количество обрабатываемых сущностей за заход ограничивается MAX_HANDLING_ENTITIES_COUNT в системе.

## WeaponTargetSelectSystem
Сравнивает текущую AttackTargetComponent и ближайшую ClosestAttackTargetComponent. Если вторая ближе и ради нее не нужно сильно отклоняться - система обновит цель.
